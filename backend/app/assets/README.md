# Шрифты для PDF

`DejaVuSans.ttf` нужен `app/services/plan_pdf.py`: стандартные Helvetica/Times в PDF
кириллицу не рисуют, и «СВЕТЛОГОРСК» превращается в пустые места.

Файл лежит в репозитории намеренно — Docker-образ собран на `python:3.12-slim`,
своих шрифтов в нём нет, а `apt-get install fonts-dejavu-core` сделал бы сборку
зависимой от зеркала Debian и от того, какая версия шрифта лежит в его репозитории:
PDF-лист обязан выглядеть одинаково на любой сборке.

* файл: `DejaVuSans.ttf` (regular, ~740 КБ, subset встраивается в PDF, поэтому
  сам файл в файл не удваивается);
* лицензия: DejaVu Fonts — свободная (наследует разрешение Bitstream Vera:
  свободное использование, копирование и распространение, включая встраивание
  в документы; шрифт нельзя продавать отдельно от продукта, порождённые имена
  не должны содержать «DejaVu»);
* источник: https://dejavufonts.github.io/ (текст лицензии — `LICENSE` в релизе).

Если понадобится полужирный — добавлять `DejaVuSans-Bold.ttf` тем же списком в
`_FONT_CANDIDATES`, курсив плану не нужен.
