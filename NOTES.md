## Долг и чем он пахнет

- **Планировщик живёт в каждом воркере uvicorn.** При `UVICORN_WORKERS=2` синхронизация
  проходит дважды за интервал: `threading.Lock` из п.10 работает только внутри процесса.
  Нужен advisory-лок PostgreSQL или отдельный процесс-синхронизатор.
- **Кэш витрины — в памяти процесса.** Корректен при любом числе воркеров (версия считается
  по меткам таблиц), но после `invalidate()` первый запрос в каждый воркер считается заново.
  Условия переезда в Redis перечислены в докстринге `data_cache.py`.
- **Миграций нет**: `create_all` + `_ADDED_COLUMNS`. Как только в проде появятся боевые
  данные — Alembic, и это больно откладывать.
- **Внешние ключи SQLite выключены** — сирот (удалённый причал/пользователь) не будет видно
  вообще, чистить обязан код.
- **Раздутые файлы**: `VesselsPage.tsx` 1569, `StatisticsPage.tsx` 1378, `plan_pdf.py` 1030,
  `test_vessels.py` 1480, `tools/ui_vessels.mjs` 791. Любая правка постановки задевает сразу
  несколько из них — перед крупными изменениями стоит разрезать `VesselsPage` (сетка /
  перетаскивание / модалка / PDF-кадр).
- **`requirements-dev.txt` ставит свежие колёса, `requirements-prod.txt` — пин.** Зелёный
  прогон на dev не гарантирует той же картины в образе Docker.
- **Один сетевой тест** (8.8 с) тянет весь прогон; п.13 = fake-транспорт вместо реального URL.

## Мелочи, экономящие час

- После правок палитры в `tailwind.config.js` — перезапустить vite и почистить
  `node_modules/.vite`, иначе браузер отдаёт старый CSS и проверки по скриншотам врут.
  Проверять `getComputedStyle`, а не глазами.
- Браузерные смоки ходят на `:5173` (`BASE=...`), нужен Chromium: `PW_CHROMIUM=<путь к chrome.exe>`.
- `tools/pdf_arrow_parity.py` требует поднятый бэкенд с цепочкой перешвартовок;
  `tools/plan_pdf_preview.py` смотрит лист без браузера.
- После смоков чистить dev-базу от `qa*`/`zz*`, `QA-%` и `app_settings` — иначе проверки
  размеров зависят от прошлого прогона.
- `CELL_H` (12 px) обратно не увеличивать; `SLOT_W` остаётся дробной, округление оставляет
  пустую полосу справа.
- `from __future__ import annotations` + `datetime` в `Query(...)` не работает — даты в query
  строкой и `datetime.fromisoformat`.
- Вложенная в `.panel` модалка запирается в карточке (`backdrop-filter` + `fixed`): только
  `createPortal(…, document.body)`.
- `api.planPdf` — отдельный `requestBlob`, обычный `request` ломает бинарь и глотает `ApiError`.
- `D:/basis/data/statcab.db` (0 байт) — пустая база вне репозитория, следствие запуска с
  относительным путём. Реальные данные лежат в `backend/data/statcab.db`.
