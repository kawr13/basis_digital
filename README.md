# Кабинет веб-статистики · БазисПорт

Сервис для менеджеров и топ-менеджмента: **остатки грузов, ёмкость складов, динамика
обработки** — в удобочитаемом виде. Источник цифр — **1С**, кабинет только читает витрину.

Стек: FastAPI + SQLAlchemy + PostgreSQL · React + Vite + Tailwind · Docker Compose.

---

## Быстрый старт (разработка, без Docker)

```bash
# бэкенд
cd backend
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m pytest                                     # 12 тестов на авторизацию и доступ
uvicorn app.main:app --reload --port 8000
```

При первом запуске создаётся SQLite-база и администратор — **пароль печатается в лог**,
смените его сразу. Демо-менеджеры: `petrov` / `sidorova` / `ivanova`, пароль `demo1234`
(только в dev, в prod их не будет).

```bash
# фронт (в другом терминале)
cd frontend
npm install
npm run dev                                          # http://localhost:5173, API проксируется на :8000
```

## Прод (Docker Compose)

```bash
cp .env.example .env        # заполнить POSTGRES_PASSWORD и SECRET_KEY
docker compose up -d --build
docker compose logs backend | grep администратор
```

Кабинет — на `http://localhost:8080`. Дальше ставится за ваш nginx/HTTPS
(см. `frontend/nginx.conf` как образец: `/api` проксируется в бэкенд, фронт — SPA).

## Переключение на настоящую 1С

1. Программист 1С публикует HTTP-сервис по контракту `docs/03_контракт_1с.md`
   (4 GET-эндпоинта, учётка только для чтения).
2. В `.env`: `ONE_C_SOURCE=http`, `ONE_C_BASE_URL=http://<1c-server>/StatCabinet`,
   логин/пароль отдельной учётки 1С.
3. `docker compose up -d` → `curl -X POST localhost:8080/api/sync/run` (под админом).

Пока 1С нет — `ONE_C_SOURCE=mock`, цифры демонстрационные, но структура и экраны настоящие.
